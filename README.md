## Descripció

Aquesta aplicació és un diari esportiu per registrar i seguir entrenaments de córrer i calistenia. Permet anotar les sessions, revisar el historial i fer un seguiment del progrés. Està construïda amb Angular 22 i es farà servir com a projecte base durant tot el semestre del mòdul DA2_OA01.
